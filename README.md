# The World in One Day — Monday 23 November 2026

A one-page front page that sums up the world's news of Monday
23 November 2026 in a single image. The program draws everything
itself — masthead, headlines, numbers, pictograms and a world map —
with a vector stroke font written for this entry. Pure Python 3.13
standard library only (no Pillow, no numpy, no network); the output
is deterministic, two runs produce byte-identical PNGs.

## How to run

```
MAKEFUN_OUTPUT_DIR=out python3 main.py   # writes out/entry.png
```

The image is 1024x1024, well under the 1 MiB limit.
